## 🚀 Featured Projects

### 📁 Enterprise RAG System
> Hybrid retrieval QA system with 98%+ precision and near-zero hallucination

- **Architecture:** FAISS + BM25 + Cross-Encoder Reranking
- **Chunking:** Semantic chunking with overlap (replaced fixed-size)
- **Optimization:** KV-cache tuning + async batching
- **Result:** 52% → 88% accuracy, 800ms → <300ms latency

### 📁 LLM Inference Pipeline
> Production-grade inference serving for real-time applications

- **Techniques:** Continuous batching, KV-cache optimization
- **Evaluation:** Automated model benchmarking framework
- **Result:** 25% cost reduction without quality loss

### 📁 Fine-Tuning Pipeline
> End-to-end pipeline for domain-specific model training

- **Methods:** LoRA, QLoRA, FSDP fine-tuning
- **Alignment:** DPO training for instruction following
- **Evaluation:** Custom benchmark suite
